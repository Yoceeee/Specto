# Specto

A **Specto** egy Androidra készült média-követő/felfedező alkalmazás, amely a szakdolgozati projektemként készült. Célja, hogy a felhasználók egy letisztult felületen követhessék nyomon a megtekintett filmeket és sorozatokat.

## Főbb funkciók
* Média keresése és hozzáadása a személyes listához.
* Kedvencek és megtekintett tartalmak egyszerű kezelése.
* Felhasználói adatok szinkronizálása a felhővel.

## Telepítés (kipróbálás)

Az alkalmazás kipróbálásához kövesd az alábbi lépéseket:

1. Látogass el a projekt [Releases](../../releases/latest) oldalára.
2. Töltsd le a legújabb **`.apk`** fájlt az *Assets* rész alól.
3. Nyisd meg a letöltött fájlt az Androidos eszközödön.
4. A biztonsági figyelmeztetésnél engedélyezd az *"Ismeretlen forrásokból"* származó alkalmazások telepítését.
5. Telepítsd, és már használhatod is!

## Használt technológiák
* **Nyelv:** Java 
* **Adatbázis:** Room (lokális adattárolás) és Firebase (felhő szinkronizáció)
* **Architektúra:** MVVM
